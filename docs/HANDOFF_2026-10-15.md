## Software and navigation changes

The new `studio navigate` command produces an offline searchable HTML index and JSON inventory. It links scripts, representative art, native projects, review records and recovery candidates without moving source files. It distinguishes missing files, unassigned files, LFS pointers and digest mismatches; file existence never grants approval.

The desktop job handler now decodes byte output from a timed-out subprocess before combining it with stderr. Previously a timeout could itself raise a type error and hide the useful render output. Scene loading also reads the episode table once instead of rereading it for each of 128 shots. The existing local desktop workspace implementation is included with its tests and usage guide.
