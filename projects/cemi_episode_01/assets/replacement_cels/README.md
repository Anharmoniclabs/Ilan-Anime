# Replacement-cel experiments

Generated after the author rejected broad mesh deformation. These are source atlases for review, not finished motion or approved model sheets.

- `beheto_eight_poses.png`: 4×2 intended sequence of palms approaching, contacting, pressing and settling. Transparent PNG; placement, drum registration and edge quality need correction.
- `lead_canoe_eight_poses.png`: 4×2 intended paddling cycle with Dairon, Yara, Amaia and sleeping son. Transparent PNG; the hull and paddle-side changes need correction before animation.
- `children_six_poses_unapproved.png`: 3×2 intended look/turn/brace sequence. Alpha/background quality and child identity/age need review.
- `drum_clean_plate.png`: empty canoe/environment derived from the S01-11 keyframe. No character is animated in this file.

Generation used the built-in image tool with S01-11 and S01-12 as visual references. Intended invariants were character identity, camera, navy/amber shading and rigid hull/drum geometry. Generated outputs do not consistently guarantee those invariants; review the actual pixels.

No mesh warping, optical-flow interpolation or background crossfading has been applied to these atlas files. They have not yet been split into registered production cels.
